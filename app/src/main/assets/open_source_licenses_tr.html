Üçüncü Taraf Yazılım Lisansları

AquaLight, çeşitli açık kaynak kütüphaneler kullanılarak geliştirilmiştir. Bu projelerin geliştiricilerine teşekkür eder, başlıca bileşenleri ve lisanslarını aşağıda listeleriz.

Kullanılan kütüphaneler

  • AndroidX Media3 — ExoPlayer ve kullanıcı arayüzü bileşenleri. Apache License 2.0.
  • Material Components for Android — Apache License 2.0.
  • Firebase SDK for Android — Firebase ve Apache tarzı lisanslar.
  • BlurView by eightbitlab.com — Apache License 2.0.
  • Jetpack DataStore ve Protocol Buffers çalışma zamanı — Apache License 2.0 ve BSD tarzı lisanslar.
  • AndroidX Core Libraries — Navigation, AppCompat, ConstraintLayout ve diğerleri. Apache License 2.0.
